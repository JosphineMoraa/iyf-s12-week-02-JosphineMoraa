# My Portfolio — Week 2

This project is my Week 2 portfolio exercise. It brings together HTML pages, CSS styling, and images.

## Work I completed

- Created a home page with links to the About, Projects, and Box Model pages.
- Added portfolio content to the About and Projects pages.
- Used a shared stylesheet to style the pages and make the project cards responsive.
- Added images to the portfolio.

## Challenges I faced

- Organizing the files so the home page is named `index.html` and sits in the main project folder.

- Learning how to stage, commit, and push my changes using VS Code.

## What I learned

I practiced the CSS box model, page layout, responsive styling, and the steps for publishing project changes with Git and GitHub.
