## Project Description
A personal portfolio website created to practice HTML and CSS. It includes a home page with navigation, About and Projects pages, and a Box Model practice page.

## Technologies Used
- HTML5
- CSS3

## Features
- Navigation arranged with Flexbox.
- A responsive project grid with one column on small screens, two columns from 700px, and three columns from 1000px.
- About, Projects, and Box Model pages styled with a shared stylesheet.
- Portfolio images and hover styling for project links.

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.

## Lessons Learned
I practiced the CSS box model, Flexbox, CSS Grid, and responsive styling. I learned how file paths connect HTML pages to CSS and images, and how to save and share project changes using GitHub.

## Challenges Faced
- Organizing project files so `index.html` is in the repository root.
- Correcting links to the shared stylesheet and image files.
- Learning to stage, commit, and push changes in VS Code.
