# Week 2: Responsive Portfolio Website

## Project Description
A personal portfolio website made to practice HTML and CSS. It includes a home page, About page, Projects page, and Box Model practice page.

## Technologies Used
- HTML5
- CSS3

## Features
- Flexbox navigation.
- Responsive project grid: one column on phones, two on tablets, and three on desktop screens.
- Portfolio images and hover styling.

## How to Run
Open `index.html` in a web browser.

## Lessons Learned
I practiced the CSS box model, Flexbox, CSS Grid, and responsive styling.

## Challenges Faced
- Organizing files so the home page is in the repository root.
- Linking pages to the stylesheet and images correctly.
- Learning to stage, commit, and push changes in VS Code.
