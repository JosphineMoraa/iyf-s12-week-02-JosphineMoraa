# Week 2: Responsive Portfolio Website

## Project Description
A personal portfolio website made to practice HTML and CSS. It includes a home page, About page, Projects page, and Box Model practice page.

## Technologies Used
- HTML5
- CSS3

## Features
- Flexbox navigation.
- Responsive project grid: one column on phones, two on tablets, and three on desktop screens.
- Portfolio images and hover styling.

## How to Run
Open `index.html` in a web browser.

## What i Learned
I practiced the CSS box model, Flexbox, CSS Grid, and responsive styling.
- I learned how the CSS box model affects the size and spacing of elements.
- I learned to use Flexbox and Grid to organize page layouts.
- I learned how to make a website responsive for different screen sizes.
- I learned to use colors, fonts, and spacing consistently.
- I improved my spelling while writing and reviewing the README.
  
## Challenges Faced
- Organizing files so the home page is in the repository root.
- Linking pages to the stylesheet and images correctly.
- Learning to stage, commit, and push changes in VS Code.
- Getting the layout to look right because the CSS box model was confusing.
- Choosing between Flexbox and Grid for different parts of the page.
- Making the portfolio look good on both mobile and desktop screens.
- Fixing spacing, alignment, or sizing issues while styling the pages.
- Picking colors and fonts that looked consistent across the site.
- Getting hover effects or the responsive navigation to work as intended
